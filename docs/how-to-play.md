# How to play

## Start

Run `python3 -m http.server` in the project folder and open `localhost:8000`.

## Controls

| Action | Keys |
|---|---|
| Move | Arrow keys or W A S D |
| Confirm (advance dialogue, talk, pick an answer) | **Z** or Enter |
| Cancel (leave a puzzle) | X or Esc |

The game opens on an intro dialogue. Arrow keys do nothing there. Press **Z** or Enter to read through it, then you can walk.

## The screen

- Red square: you.
- Purple square: a character. Stand next to one and press Z to talk.
- Brown tile: a closed door. Walk into it to see why it is closed.
- Yellow tile: the exit to the next map.

## Puzzles

1. Talk to a character (Z). Read the dialogue (Z) until the puzzle appears.
2. Move the `>` cursor with Up and Down. Press Z on an answer.
3. Some puzzles ask for one correct answer. Others ask you to pick items in the right order, and the picked items show above the list as "Montado".
4. A wrong answer shows a hint with the passage to reread. There is no game over, try again.
5. Solving a puzzle opens its matching door. Press X to leave a puzzle without solving it.

Solve every puzzle on a map, walk through the open doors to the yellow exit, and the next map starts.
